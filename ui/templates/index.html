Gmail Inbox

App password · IMAP (read-only)

Fetches emails received in the last N hours and runs them through the full CLR pipeline. Results appear in Dashboard and Insights.

Setup — one time only:

  1. Turn on 2-Step Verification on your Google account (myaccount.google.com/security)
  2. Generate an App Password at myaccount.google.com/apppasswords (app: Mail)
  3. In Gmail, go to Settings → Forwarding and POP/IMAP and enable IMAP access
  4. Add your address to .env in the project root: 
    CLR_GMAIL_ADDRESS=you@gmail.com
  5. Run python main.py from a terminal and enter the app password when prompted (it's never written to disk)
  6. Once the server is running, click Check Connection above
